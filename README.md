# Automatize

## Sobre o projeto

O **Automatize** propõe uma solução para auxiliar uma profissional da área de estética e beleza na organização de seus **agendamentos e atendimento aos clientes**.

Atualmente, processos como agendamento, remarcação, cancelamento, confirmação de horários e envio de lembretes podem ser realizados manualmente, aumentando o risco de conflitos de horários, esquecimentos e períodos ociosos.

A proposta é desenvolver uma solução integrada que automatize parte desses processos e facilite o gerenciamento da agenda.

## Solução

A arquitetura proposta é dividida em três principais partes:

* **Mobile:** interface para interação com os clientes e gerenciamento dos agendamentos.
* **API:** responsável pela comunicação entre o aplicativo, banco de dados e regras do sistema.
* **Python:** responsável por automações, como verificação periódica da agenda, identificação de conflitos e gerenciamento de lembretes.

O projeto também utiliza um **banco de dados** para armazenar as informações necessárias para o funcionamento da aplicação.

## Objetivos

* Reduzir tarefas manuais relacionadas à agenda;
* Diminuir conflitos e esquecimentos de horários;
* Facilitar o gerenciamento dos agendamentos;
* Melhorar a organização do atendimento;
* Integrar conhecimentos de Python, API, banco de dados e desenvolvimento mobile.
